# Carbon Footprint Calculator — Construction Materials

How much CO2e is hidden in the materials of a building project?

A Python project that calculates the carbon footprint of construction materials (concrete, steel, aluminium) based on their mass and emission factor. Built to practice OOP — inheritance and polymorphism — in a real-world sustainability context.

## Example

Ślad węglowy wszystkich materiałów budowlanych wynosi 35758367.96

Do najbardziej emisyjnych materiałów należą: ['Beton Gliwice', 'Stal Wrocław', 'Aluminium Kraków']
